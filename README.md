# About GTSS Library

The GTSS Library helps you find traffic signal data, create GTSS data, and regularly publishes a JSON file of all the GTSS Datafiles we know of.

## What is GTSS?

GTSS is the General Traffic Signal Specification, a standardized format for describing traffic signal agencies, locations, phases, and detection equipment.
